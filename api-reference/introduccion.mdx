Bienvenido a **SharkFac Lite**, la plataforma de facturación electrónica SIAT más rápida y moderna de Bolivia. Nuestro objetivo es que dejes de pelear con los complicados manuales de Impuestos Nacionales y empieces a facturar en minutos.

Ya sea que tengas un pequeño negocio o un ERP gigante, nuestra API REST está diseñada para ser integrada fácilmente en cualquier lenguaje de programación.
